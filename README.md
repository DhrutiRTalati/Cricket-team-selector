# Cricket Team Selector

  Description
This project simulates an IPL-style auction where the best 11 players are selected within a given budget.

 Algorithms Used
- 0/1 Knapsack (Dynamic Programming)
- Greedy Approach

 Features
- Selects best players within budget
- Maintains team balance (batsmen, bowlers, etc.)
- Suggests best remaining player
- Interactive terminal UI

 How to Run
```bash
python cricket_team_selector.py
